国勢調査の階層に基づく攻略地域の表示名（2026-11-20）

対象: 配布元9ccb26beb865dd684ba304000ace6ec12e1b1b3dの全141900攻略地域。
全国47都道府県の2020年国勢調査第2表の大字・町名、字・丁目名を使用する。
元地域220814件すべてを、準備済みlegacyデータの対応で攻略地域に対応させた。
住所の境界と統計区域の境界が一致することを意味しない。
文字列の反復削除や、原本の誤記・名称作成経緯の推定は行わない。

ユーザー合意の表示ルール（重複は同じ市区町村の実際の攻略地域単位で判定）:
1. 原本は保持し、表示選択に使う上位・下位名の先頭の大字・小字を省く。
   これらの有無で別の上位名・下位名として扱わない。
   上位名が一意なら上位名を使う。
2. 上位名が重複し、単一の下位名で区別できるなら下位名を使う。
3. 下位名でも重複する場合、上位名と下位名を併記する。
   上位名だけを使う別地域との衝突も検査する。
4. 同じ上位名のグループに下位名空欄の地域があれば、そのグループは併記に統一。
   空欄はそのまま扱う。稲田町＋空欄→稲田町、稲田町＋東二線→稲田町東二線。
5. 複数下位名を統合していても、上位名で最終的に一意なら上位名を使う。
   夕張市: 鹿の谷／山手町／東丘町。鹿の谷に一～三丁目を付加しない。
6. 上位名や下位名を一つに決められない統合地域では、既存の統合名を保持する。
   併記にも既存統合名を使い、下位名を恣意的に一つ選ばない。
   大字・小字の接頭辞を原本から復活させて区別する処理は行わない。
   既存統合名を使う場合も、原本の上下位名の境界で確認した小字は省く。
7. 最終表示名が衝突したら、一意な上位名を優先して保持し、
   下位名側の地域を完全な既存統合名へ広げ、再検査する。
   複数上位名の統合地域に含まれる上位名も、重複判定の対象に含める。
8. 上下位名とも空欄の名称未設定117攻略地域はそのまま維持する。

結果: 表示名変更34955地域、名称未設定117地域維持。
小字省略の追加適用は大山崎町82地域・精華町259地域の計341地域。
例: 小字藤井畑→藤井畑、小字夏目→夏目、祝園小字池頭→祝園池頭。
合意ルールでも区別できない同名376組・752地域は既存の同名表示を保持する。
新しい同名の組は発生していない。unresolved-names.jsonに全対象IDを記録する。
青森市: 022010760と022011350はともに上位古館・下位空欄。
鶴岡市: 06203247020と06203247023はともに黒川＋字大杉川原。
こうした地域に独自の例外や大字を付けず、統合やIDも変えない。
田辺田辺→田辺、田辺一休ケ丘→一休ケ丘、田辺新田辺西住宅→新田辺西住宅。
河原河原→河原も同じルールで選択する。吉里吉里は保持する。
これらは表示ルールによる採用であり、原本の誤りを認定したものではない。

実装と互換性:
lib/town_display_names.dart から生成済みの地域ID別表示名表を参照する。
期待する既存統合名が一致したときだけ適用する。
Town.name、元データ、compactデータ、統合方法、ID、人口、面積、隣接、境界を維持。
fromJsonとfromPrepared/CompactTownsの両経路で共通のTown.displayNameを使う。
地図ラベル・一覧・検索・クイズと予習に同じ表示名を使う。
クイズ保存と正誤判定は従来の回答文字列を維持し、表示時のみ変換する。
既存統合名が同名の場合も、人口最大・役所所在地の設問が指す攻略地域から
表示名を選ぶ。粕屋町の仲原と苅田町の与原も大字接頭辞を復活させない。
原文字列だけで全候補を一括置換しない。

根拠と再現:
source-receipts.json: 47原本CSVのe-Stat取得URL、表ID、SHA-256。
source-fields.csv.gz: 原本から対象220814件のID、上位名、下位名をそのまま抽出。
selected-names.csv.gz: 全攻略地域の元統合名、表示名、適用ルール、上下位名集合。
summary.json: 件数、分類、入力ハッシュ。
unresolved-names.json: 合意ルールでも区別できない既存同名の全対象。
生成物は安定順で出力する。source-fields.csv.gzの原本フィールドは変更せず、
selected-names.csv.gzの上下位名集合は大字・小字省略後の判定用フィールドを記録する。

python tools/generate_town_display_names.py --check
原本CSVをpref-01-table2.csv～pref-47-table2.csvとして取得したディレクトリがあれば:
python tools/generate_town_display_names.py --estat-dir /path/to/csvs --check
原本SHA-256と全220814件のフィールドが一致することも検証する。
