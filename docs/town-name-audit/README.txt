2020年国勢調査の統計地区名とアプリ表示名の照合（2026-11-19確認）

今回の表示補正は1地域のみ:
  国勢調査地域ID 26211010001、京田辺市
  原本・統合用名称 田辺田辺 → アプリ表示名 田辺

原本名称は誤記と断定せず、その作られ方も推定しない。
地域ID、町の統合、人口4911人、面積、境界、隣接、保存用名称は変更しない。
田辺の統計区画には複数の住所地名が含まれる。
今回の表示名採用は、区画全体がABRの単一町字の境界に等しいという判断ではない。

確認根拠:
・CODH r2ka26211.topojson 原本を再取得し、引き継ぎのSHA-256と一致。
  KEY_CODE 26211010001 / S_NAME 田辺田辺 / JINKO 4911。
・デジタル庁ABR町字マスター（ユーザー提供ZIP）:
  lg_code 262111、machiaza_id 0594000、machiaza_type 1、
  oaza_cho 田辺、chomeとkoazaは空欄。
  ABRのIDと国勢調査地域IDは別体系であり、文字列や番号だけで対応させない。
・国土交通省「位置参照情報」2020年版・2025年版の「田辺」:
  大字町丁目コード262110280000、緯度34.814761、経度135.768415。
  両年の点がCODH地域26211010001のポリゴン内部に存在することを照合。
  最新ABRの存在やefct_dateだけを2020年対応の根拠にはしていない。
・京田辺市「京田辺水道のあゆみ」:
  昭和62年の移転先は田辺田辺80、平成17年の移転元は田辺80と記載。
  https://www.city.kyotanabe.lg.jp/0000000240.html
・京田辺市「住所対応表（た行）」で田辺の住所・行政区等表記を確認。
  https://www.city.kyotanabe.lg.jp/0000014297.html

河原河原（26211012001）は保留:

  https://www.city.kyotanabe.lg.jp/0000014295.html

  全373レコード、82市区町村、23都道府県。

  ABR全727533行を走査し、該当82市区町村40040行を候補と照合。

実装:
  lib/town_display_names.dart の地域IDと期待する原本名を一致確認して補正。
  Town.nameは従来どおり原本・統合・クイズ保存に使用し、Town.displayNameを表示に使用。
  Atlas.fromJsonとAtlas.fromPrepared/CompactTownsの両経路で同じgetterを使う。
  国勢調査元データ・準備済みメタデータ・地図データの再生成や名称書き換えは行わない。
  地図ラベル、一覧、検索、選択表示、獲得メッセージ、クイズ・予習に共通の表示名を使う。
  クイズの回答と選択肢は保存時の原文字列を保ち、ボタン表示だけを変換する。
  コールバックと正誤判定にも原文字列を渡すため、旧クイズの現在問・残り問を維持できる。
  町名が答えになるlargest/office問題だけを変換し、市区町村内の名称対応を確認する。
  将来の補正で表示が重複する場合は、曖昧な選択肢にせず元の名前へフォールバックする。
